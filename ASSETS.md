# Assets and provenance

This repository collects project code, user-provided assets, generated artwork, and scientific references. Their inclusion does not grant a blanket license to redistribute third-party or user-provided media. No NASA endorsement is implied.

| Files                                                                                  | Origin and use                                                                                                                                                                                                                                                      |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `assets/source/ARES_04_Rover.blend`                                                    | The user's Blender rover project. The game uses an evaluated export with separate body and four wheel groups in `src/ares4-mesh.js`. ARES is fictional and differs from Curiosity's six-wheel vehicle.                                                              |
| `assets/source/intro.mov`                                                              | The user's original supplied `intro media.mov`. No authorship or redistribution license was supplied with the clip.                                                                                                                                                 |
| `src/intro.mp4`                                                                        | Browser-compatible H.264 MP4 converted from the supplied movie through Windows Media Foundation. It is about 4.563 seconds long and preserves the original display rotation.                                                                                        |
| `src/intro-background.png`                                                             | Generated using the built-in image-generation tool for this project. The prompt and conversion notes are in [docs/intro-background-generation.json](docs/intro-background-generation.json). The video's embedded black pillars are masked to reveal this landscape. |
| `src/gale-reference.jpg`, `assets/source/gale-reference.rgb`, `src/gale-topography.js` | The supplied color Gale topographic map and image-derived conversion inputs/output. The fallback heights are estimates from map colors, not an imported digital elevation model. Original image authorship was not established from the supplied file alone.        |
| `src/landing-reference.jpg`                                                            | User-supplied Curiosity landing panorama, credited in the game to NASA/JPL-Caltech/MSSS. Used as an appearance reference. Missing black image areas are not terrain geometry.                                                                                       |
| `src/traverse-landing.png`, `src/traverse-kimberley.png`, `src/traverse-gediz.png`     | User-supplied NASA map screenshots. The first two are registered to an approximate common map for the route. The Gediz reference is retained without an invented connection or geographic placement.                                                                |
| `src/traverse-data.js`                                                                 | Simplified snapshot of NASA’s published rover path, with screenshot-estimated landmark positions and source links.                                                                                                                                                  |
| `src/landing-reference.js`, procedural rocks and surface detail                        | Illustrative generated layout/color choices for the game. They are not measured rock locations or a geological classification map.                                                                                                                                  |
| Optional imported MOLA crop                                                            | User-selected NASA PDS source data, stored in browser local storage. The original 130 MB tile is not bundled. Synthetic test data is never shipped as measured terrain.                                                                                             |
| Google Fonts CSS                                                                       | Optional remote font styling requested by `src/styles.css`; the game includes local fallback font families.                                                                                                                                                         |
| `history/`                                                                             | Earlier code, generated outputs, patch scripts, and snapshots. Preserved for development context; not the active runtime or reproducible build pipeline.                                                                                                            |

Primary scientific references already used by the game:

- [NASA PDS MOLA MEGDR documentation](https://pds-geosciences.wustl.edu/missions/mgs/megdr.html).
- [MOLA topography image](https://pds-geosciences.wustl.edu/mgs/urn-nasa-pds-mgs_mola_topography_derived/meg128/megt00n090hb.img) and [matching PDS label](https://pds-geosciences.wustl.edu/mgs/urn-nasa-pds-mgs_mola_topography_derived/meg128/megt00n090hb.lbl).
- [NASA MSL landing reconstruction](https://ntrs.nasa.gov/api/citations/20130010129/downloads/20130010129.pdf), used for the Bradbury Landing anchor at approximately 4.5895° S, 137.4417° E.
- [NASA early landing panorama](https://science.nasa.gov/photojournal/gale-crater-vista-in-glorious-color/).
- [NASA landing-to-Pahrump route chronology](https://www.jpl.nasa.gov/images/pia18607-curiosity-mars-rovers-route-from-landing-to-pahrump-hills/).
- [USGS Gazetteer: Gale](https://planetarynames.wr.usgs.gov/Feature/2071), used as the approximate center tie point for the image-derived fallback.

The game starts at the first coordinate in NASA’s published rover path near Bradbury Landing. Brightness, lighting, fine texture, suspension, traction, and accelerated driving remain artistic or gameplay choices.
